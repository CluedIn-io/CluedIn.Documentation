# Hierarchies

Hierarchy Builder helps you organize, visualize, and manage relations between golden records within and across different business domains.

![How to build hierarchies in CluedIn: 1 select a business domain, 2 select an edge type, 3 select top-level roots, 4 select a hierarchy project mode, 5 review and modify the hierarchy, 6 publish the hierarchy](https://documentation.cluedin.net/assets/images/management/hierarchy-builder/hierarchy_builder.gif)

This section covers the following topics:

- [Concept of hierarchy](https://documentation.cluedin.net/model/hierarchies/concept-of-hierarchy.md) – explore hierarchies through an example of Organization-Project-Employee hierarchy.

- [Create a hierarchy](https://documentation.cluedin.net/model/hierarchies/create-a-hierarchy.md) – learn about various options for creating a hierarchy.

- [Work in a hierarchy project](https://documentation.cluedin.net/model/hierarchies/work-in-a-hierarchy-project.md) – learn how to modify a hierarchy, load golden records of other business domains into the hierarchy, and use various tools to make working in the hierarchy project more convenient.

- [Manage hierarchies](https://documentation.cluedin.net/model/hierarchies/manage-hierarchies.md) – learn how to clone, export, and delete a hierarchy.
