# Relationships

Relationships - edges - connect one record to another: an employee to an organization, an order to a customer. They are part of the model, and they are what makes the graph in CluedIn navigable.

For relationships as they appear on a golden record, see [Golden record relations](https://documentation.cluedin.net/master/golden-records/golden-record-relations.md).

## In this section

- [Relationships (edges)](https://documentation.cluedin.net/model/relationships/edges.md) (concept): An edge defines a relation between two records in CluedIn.
- [Tutorial: add relations between records](https://documentation.cluedin.net/model/relationships/tutorial-add-relations.md) (tutorial): Relations are built between source ("to") and target ("from") records by using edges of a certain type (for example, /WorksFor).
