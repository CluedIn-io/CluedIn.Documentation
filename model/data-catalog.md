# Data catalog

A data catalog is a collection of metadata that encompasses essential information about the organization, structure, usage, and lineage of data within the system. It comprises vocabularies and vocabulary keys, acting as fundamental building blocks for constructing a comprehensive data model.

The following diagram shows the basic steps of defining a data model in CluedIn.

![How to define a data model in CluedIn: 1, create a vocabulary; 2, add vocabulary keys that describe golden records; 3, update the data model iteratively as requirements change](https://documentation.cluedin.net/assets/images/management/data-catalog/data-catalog.gif)

This section covers the following areas:

- [Modeling approaches](https://documentation.cluedin.net/model/data-catalog/modeling-approaches.md) – explore the options available for building data models and learn how to use vocabulary key mapping to unify your model across various sources.

- [Vocabularies](https://documentation.cluedin.net/model/vocabularies/manage-vocabularies.md) – learn how to create and manage vocabularies for storing and organizing groups of vocabulary keys.

- [Vocabulary keys](https://documentation.cluedin.net/model/vocabularies/vocabulary-keys.md) – learn how to create and manage vocabulary keys for defining characteristics of golden records.

- [Search the data catalog](https://documentation.cluedin.net/model/data-catalog/search-data-catalog.md) – learn how to make the process of finding metadata faster and more efficient by using filters.

- [Data types](https://documentation.cluedin.net/model/data-catalog/data-types.md) – find reference information about data types that can be used in vocabulary keys.
