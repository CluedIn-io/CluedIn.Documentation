# Archive

Where did the old material go?
  Maintainers.

Material kept for reference but no longer part of the supported documentation: features that were withdrawn, developer documentation for older platform versions, and superseded operational runbooks.

Nothing here should be linked from the product documentation. Pages keep the `published: false` flag they already carried, so they do not render on the live site - they are retained so the history is not lost.

## In this section

- [Legacy development documentation](https://documentation.cluedin.net/archive/legacy-development.md): Developer documentation for earlier versions of the platform.
- [Legacy user interface documentation](https://documentation.cluedin.net/archive/legacy-user-interface.md): Descriptions of the CluedIn interface from before the 2025.05 terminology change, when golden records were called entities.
- [Unsupported features](https://documentation.cluedin.net/archive/unsupported-features.md): Features that were documented but are no longer supported.
- [Historical operations](https://documentation.cluedin.net/archive/historical-operations.md): Operational runbooks kept for installations that have not yet been upgraded, and superseded drafts.
