# Processing

Processing turns mapped records into data parts and golden records. Preview and validations let you check what will happen before you commit; approval puts a gate in front of it.

## In this section

- [Process data](https://documentation.cluedin.net/ingest/processing/process-data.md) (how-to): Process a data set to turn its records into standalone golden records, or to use them to enhance existing golden records.
- [Preview](https://documentation.cluedin.net/ingest/processing/preview.md) (how-to): In this article, you will learn about various actions available on the Preview tab of the data set to help you analyze the uploaded records and improve their quality before processing.
- [Validations](https://documentation.cluedin.net/ingest/processing/validations.md) (how-to): Check the source records of a data set for errors, inconsistencies, and missing values, and fix invalid values before you process the data set.
- [Approval](https://documentation.cluedin.net/ingest/processing/approval.md) (how-to): In this article, you will learn how to implement source record approval, which allows you to approve or reject specific records and ensure that only verified records are sent into processing.
- [Removal of records](https://documentation.cluedin.net/ingest/processing/remove-records.md) (how-to): In this article, you will learn how to remove records (also referred to as data parts) that were created from a specific data source.
