CluedIn takes messy data from many systems and turns it into golden records you can trust. This section explains what the platform does, defines the terms used everywhere else in the documentation, and walks you through your first end-to-end run.

Once you are oriented, the rest of the documentation follows the data lifecycle: [Ingest](/ingest) -> [Model](/model) -> [Master](/master) -> [Govern & improve](/govern) -> [Publish & consume](/publish).
