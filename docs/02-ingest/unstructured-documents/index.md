Some of the most useful information in an organization never arrives as a clean, tabular data source - it is written down in reports, contracts, presentations, spreadsheets and scanned images. The **Unstructured documents** area lets you upload files like these, extract their text, organize them into folders, and use AI to turn that text into something the rest of CluedIn can work with: a classification, proposed links to existing golden records, a new record, or an update to an existing one. The area's **How it works** tab gives a quick visual summary of this pipeline without leaving the app.

This section covers the following areas:

- [Upload and extract unstructured documents](/ingest/unstructured-documents/upload-and-extract-unstructured-documents) - learn how to upload PDF, Word, PowerPoint, Excel and image files (including by dragging in a whole folder), organize them into folders, and how extraction, OCR and AI classification work.

- [Link extracted entities to golden records](/ingest/unstructured-documents/link-extracted-entities-to-golden-records) - learn how CluedIn proposes people, organizations and other entities mentioned in a document as links to existing golden records, and how to review them.

- [Create or enrich records from a document](/ingest/unstructured-documents/create-or-enrich-records-from-a-document) - learn how to turn a document into a new record, or use it to fill in missing or outdated properties on an existing golden record.
