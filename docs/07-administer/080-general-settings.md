{: .no_toc .text-delta }
- TOC
{:toc}

**General Settings** is the default page under **Organization Settings** (available from the administration menu). It gathers organization-wide settings that don't belong to a more specific settings area, such as UI preferences.

{:.note}
Looking for notification preferences? Those are per-user, not organization-wide, and live under [User settings](/administer/user-settings#notifications) instead.

## UI preferences

The **UI preferences** section controls whether users see modules in the side menu that they do not have access to. When this is enabled, users can see restricted modules and request access to them directly from the menu.
