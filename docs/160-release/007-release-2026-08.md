# 2026.08 release overview

The **2026.08 release (CluedIn 5.0)** introduces major improvements across AI-assisted data management, scheduled operations, enrichment review, deduplication, observability, and platform performance.

## AI Agent Copilot

AI Agents now include a Copilot experience that lets users configure and refine agents using natural conversation. Copilot can guide users through setting up jobs, selecting data, interpreting results, and progressing work from testing into production.

Agents can also respond to CluedIn events, such as the arrival of a new data source, so profiling, mapping, data quality checks, deduplication, and remediation can begin proactively.

For details, see [AI agents](/management/ai-agents).

## Jobs and scheduling

A new Jobs experience provides a central place to define recurring and on-demand work. Jobs can run processing rules, execute batch entity actions, use cron schedules, run immediately, and retain execution history.

System-provided background jobs are also moving onto the same jobs framework so their configuration and schedules can be managed consistently.

For details, see [Jobs](/management/jobs).

## Job Monitoring

Job Monitoring provides a consolidated view of active and historical executions across scheduled jobs and other long-running CluedIn operations. Users can inspect status, initiator, duration, and execution history and use filters to troubleshoot operational issues.

For details, see the Job Monitoring documentation.

## Enricher Multi-Match

Enrichers can now return multiple candidate matches for a golden record. The **Matches** experience lets users compare candidates, approve or reject them, and configure automatic selection using rules or AI.

For details, see [Multi-match enrichment](/preparation/enricher/multi-match).

## Global Data Model

The Global Data Model now provides more context about the ontology represented by CluedIn data. Business domains can be sized by record count, filtered by source, and displayed even when they do not yet have graph relationships.

The model also exposes which sources contribute to each business domain.

For details, see the Global Data Model documentation.

## Deduplication improvements

Deduplication projects now expose when match generation last started, making it easier to understand the freshness of generated matches and sort projects by their most recent generation.

Audit history has also been expanded to record when users start or stop deduplication automation.

For details, see [Manage a deduplication project](/management/deduplication/manage-a-deduplication-project) and [Deduplication reference](/management/deduplication/deduplication-reference).

## Rules improvements

Rule updates now support saving changes and activating an inactive rule in a single update flow. Rule audit history also records when users start or cancel rule reprocessing.

For details, see [Rule Builder](/getting-started/rule-builder).

## OpenTelemetry

CluedIn 5.0 adds OpenTelemetry support for exporting traces, metrics, and logs to an OpenTelemetry-compatible endpoint. Optional HTTP and SQL client instrumentation can also be enabled.

For details, see [OpenTelemetry](/deployment/infra-how-tos/opentelemetry).

## Performance and scalability

An optional EF Core second-level cache can reduce repeated SQL reads for low-churn data such as vocabularies, rules, glossary data, and organization settings. It uses an in-process L1 cache and Redis-based L2 cache with cross-instance invalidation.

For details, see [EF Core second-level cache](/deployment/infra-how-tos/ef-second-level-cache).

Additional performance work includes optimized bulk vocabulary operations and reduced default processing for rarely used author, temporal, and tag edge behaviors.

## API experience

CluedIn's interactive OpenAPI experience has moved from Swagger UI to Scalar. The REST API reference continues to expose endpoint schemas, parameters, authentication requirements, and response models through an interactive explorer.

For details, see [Get started with the REST API](/rest-api/get-started).
