# Python SDK

The Python SDK is the fastest way to script CluedIn: query golden records, push data in, pull data out, and automate the operations you would otherwise click through.

## In this section

- [CluedIn Python SDK](https://documentation.cluedin.net/develop/python-sdk/python-sdk.md) (reference): CluedIn provides powerful REST and GraphQL APIs.
- [Query data using GraphQL and Python SDK](https://documentation.cluedin.net/develop/python-sdk/search.md) (how-to): CluedIn provides a powerful GraphQL API that is very helpful in almost every interaction with CluedIn
- [Using Python SDK for Automation](https://documentation.cluedin.net/develop/python-sdk/automation.md) (how-to): CluedIn, as a Master Data Management system, encourages users to work with data using a UI and low-code approach.
- [Ingesting data to CluedIn with Python](https://documentation.cluedin.net/develop/python-sdk/ingestion.md) (how-to): In this article, we will explore how to ingest data to CluedIn Ingestion Endpoints with Python.
- [Exporting data to and from CluedIn with Python](https://documentation.cluedin.net/develop/python-sdk/export.md) (how-to): In this article, we will load data from CluedIn to a Databricks notebook, do basic data exploration and transformation, and save data in a Delta Lake table.
