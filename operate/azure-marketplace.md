# Azure Marketplace

Installing CluedIn from the Azure Marketplace, including the decisions to make and the checks to run before and after the managed application is deployed.

## In this section

- [Business decisions](https://documentation.cluedin.net/operate/azure-marketplace/step-1.md) (concept): In this article, you will learn about the decisions you need to make before starting the CluedIn PaaS installation process.
- [Pre-installation checklist](https://documentation.cluedin.net/operate/azure-marketplace/step-2.md) (reference): In this article, you will learn about the pre-installation processes that you must perform to ensure successful installation of CluedIn PaaS.
- [Installation guide](https://documentation.cluedin.net/operate/azure-marketplace/step-3.md) (how-to): In this article, you will learn how to install CluedIn PaaS from the Azure Marketplace.
- [Post-installation guide](https://documentation.cluedin.net/operate/azure-marketplace/step-4.md) (how-to): At this point, you have a working, secure CluedIn environment.
- [Azure requirements](https://documentation.cluedin.net/operate/azure-marketplace/requirements.md) (reference): In this article, you will learn about the Azure requirements you need to meet to ensure successful installation of CluedIn SaaS.
- [Private SaaS - Azure Market Place](https://documentation.cluedin.net/operate/azure-marketplace/installation-guide.md) (how-to): In this article, you will learn how to subscribe to CluedIn Private SaaS (via Azure Azure Marketplace) in the Azure portal and how to configure your CluedIn account.
