# Day-to-day operations

The recurring operational tasks: promoting configuration between environments, resetting an instance, migrating the database, and knowing what CluedIn support covers.

## In this section

- [Support scope](https://documentation.cluedin.net/operate/operations/support-scope.md) (reference): This article outlines the scope of CluedIn support.
- [Environment management playbook](https://documentation.cluedin.net/operate/operations/env-management-playbook.md) (how-to): This article covers best practices for using development, test, and production environments of CluedIn.
- [Reset tool](https://documentation.cluedin.net/operate/operations/reset-tool.md) (how-to): In this article, you will learn about the reset tool that you can use to restore your CluedIn cluster to its original installation state, retaining only the essential organization and user data.
- [Azure SQL migration](https://documentation.cluedin.net/operate/operations/azure-mssql-migration.md) (how-to): This document outlines the process of provisioning Azure SQL infrastructure and migrating data from an existing in-cluster SQL database to Azure SQL.
- [Azure Managed Redis](https://documentation.cluedin.net/operate/operations/azure-managed-redis.md) (how-to): This document outlines the process of provisioning Azure Managed Redis with a private endpoint and configure CluedIn to use it in place of the in-cluster Redis service.
- [Common questions](https://documentation.cluedin.net/operate/operations/common-questions.md) (reference): In this article, we address some of the most common questions related to CluedIn PaaS installation and configuration.
