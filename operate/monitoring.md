# Monitoring

Watching a running installation: the Engine Room shows what the platform is processing right now, and Log Analytics holds the detail when you need to go back through it.

## In this section

- [Engine Room](https://documentation.cluedin.net/operate/monitoring/engine-room.md) (concept): The Engine Room in CluedIn provides a visual overview of the data processing pipeline—a dependency-based tree of processing steps that define how data flows through the system.
- [Processing pipeline](https://documentation.cluedin.net/operate/monitoring/processing-pipeline.md) (concept): Conceptually, you can think of CluedIn as a streaming platform with multiple persistence stores.
- [Review logs in Log Analytics workspace](https://documentation.cluedin.net/operate/monitoring/review-logs-in-log-analytics-workspace.md) (how-to): In this article, you will learn how to review logs from all CluedIn services in your Log Analytics workspace.
- [Job monitoring](https://documentation.cluedin.net/operate/monitoring/job-monitoring.md) (how-to): The Monitoring page in Management provides a central view of jobs running across your CluedIn environment.
