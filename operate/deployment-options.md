# Deployment options

CluedIn runs as a managed SaaS service, as a private SaaS or PaaS deployment in your own Azure subscription, or locally for development. Choose the model first - it determines everything else in this section.

## In this section

- [CluedIn SaaS](https://documentation.cluedin.net/operate/deployment-options/cluedin-saas.md) (concept): Getting started with CluedIn SaaS is fast, simple, and fully self-service.
- [CluedIn Private SaaS](https://documentation.cluedin.net/operate/deployment-options/saas.md) (concept): CluedIn Private SaaS is a premium deployment model that provides each customer with a fully isolated and dedicated CluedIn environment.
- [CluedIn PaaS](https://documentation.cluedin.net/operate/deployment-options/azure-marketplace.md) (concept): CluedIn Master Data Management is an Azure Managed Application (AMA) that is deployed within your company’s Azure infrastructure.
- [Local](https://documentation.cluedin.net/operate/deployment-options/local.md) (concept): Learn how to run CluedIn locally and prepare to stream data to Microsoft SQL Server databases.
- [Pricing](https://documentation.cluedin.net/operate/deployment-options/pricing.md) (reference): In this article, you will learn about our pricing options for CluedIn SaaS and PaaS.
- [Licensing agent (PAAS)](https://documentation.cluedin.net/operate/deployment-options/marketplace-licensing-agent.md) (how-to): The CluedIn licensing agent is delivered as an Azure Managed Application and is installed via the Azure Marketplace.
- [Azure Policy exemption for deployment scripts](https://documentation.cluedin.net/operate/deployment-options/azure-policy-exemption.md) (reference): This document explains why an exemption is required for the Azure Policy currently enforcing restrictive network/firewall settings on Storage Accounts.
- [Delete CluedIn instance](https://documentation.cluedin.net/operate/deployment-options/delete-cluedin-instance.md) (how-to): This article outlines how to delete your CluedIn instance if you no longer want to use it.
