# 1.1. Ingestion

> tutorial: Guided end-to-end learning.

In the course of our comprehensive CluedIn Fundamentals training, we’ll explore how to build a single customer view by transforming disconnected data sources from CRM and ERP systems into unified and trusted golden records. This training is divided into several sessions, where you’ll learn how to perform key operations in CluedIn.

**Presented by:** Pierre Derval, Chief Product Officer at CluedIn

**Presentation:** [Download PPT](https://documentation.cluedin.net/assets/other/training-ppt/cluedin-fundamentals-what-you-will-build.pptx)

**Training plan:**

| Session | Objective | Watch time |
| :------ | :------ | :------ |
| [1.1.1. Ingesting a CSV file](https://documentation.cluedin.net/learning-paths/fundamentals/ingesting-csv-file.md) | - Ingest a CSV file containing customer records from the CRM system. | 5 mins |
| [1.1.2. Ingesting a database table](https://documentation.cluedin.net/learning-paths/fundamentals/ingesting-database-table.md) | - Ingest a database table with customer data from an ERP system. | 6 mins |
| [1.1.3. Building a single customer view](https://documentation.cluedin.net/learning-paths/fundamentals/building-a-single-customer-view.md) | - Build a single customer view by identifying and merging duplicate records from the CRM and the ERP. | 36 mins |
| [1.1.4. Identifying and labelling incorrect data](https://documentation.cluedin.net/learning-paths/fundamentals/identifying-and-labelling-incorrect-data.md) | - Identify and label invalid records using tags. | 12 mins |
