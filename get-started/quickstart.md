# Quickstart

> tutorial: Guided end-to-end learning.

This is the shortest complete path through CluedIn: get data in, make it good, and send it somewhere. Each step is a tutorial that lives with the feature it teaches, so what you learn here is the same article you will come back to later.

Work through them in order - each one assumes the previous one is done.

| # | Step | What you end up with |
|---|---|---|
| 1 | [Ingest data](https://documentation.cluedin.net/ingest/tutorial-ingest-data.md) | A data source loaded, mapped and processed into golden records |
| 2 | [Clean data](https://documentation.cluedin.net/govern/cleaning/tutorial-clean-data.md) | Obvious quality problems fixed in a clean project |
| 3 | [Deduplicate data](https://documentation.cluedin.net/master/deduplication/tutorial-deduplicate-data.md) | Duplicate records merged into single golden records |
| 4 | [Stream data](https://documentation.cluedin.net/publish/streams/tutorial-stream-data.md) | Golden records flowing to an export target |
| 5 | [Create rules](https://documentation.cluedin.net/govern/rules/tutorial-create-rules.md) | Logic applied automatically as data changes |
| 6 | [Create hierarchies](https://documentation.cluedin.net/model/hierarchies/tutorial-create-hierarchies.md) | Records organised into a parent/child structure |
| 7 | [Work with the glossary](https://documentation.cluedin.net/govern/work-with-glossary.md) | Terms that describe groups of golden records |
| 8 | [Add relations between records](https://documentation.cluedin.net/model/relationships/tutorial-add-relations.md) | Records connected to each other |

**Before you start.** You need access to a CluedIn instance. If you do not have one yet, see [How to get CluedIn](https://documentation.cluedin.net/get-started/get-cluedin.md) and [Getting access](https://documentation.cluedin.net/get-started/getting-access.md).

Up: [Get started](https://documentation.cluedin.net/get-started.md)
