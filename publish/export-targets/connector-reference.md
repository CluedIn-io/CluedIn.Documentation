# Connector reference

> reference: Facts, options, APIs.

In this article, you will find reference information about built-in connectors in CluedIn.

> **Important:** Please note that the connectors are not included in the CluedIn license. Each connector is an open-source package provided by the CluedIn team for free to help you send your golden records to external systems.

## Amazon S3

The [Amazon S3](https://documentation.cluedin.net/publish/export-targets/amazon-s3-connector.md) connector allows you to publish data from CluedIn to an Amazon S3 bucket.
