{%- comment -%} Pick the colour scheme before the page paints. The theme compiles one stylesheet per scheme (clue / clue-dark); ciSetScheme swaps between them. An explicit choice from the toggle wins, otherwise the OS preference does. ciSetScheme replaces jtd.setTheme only to add a build-time version to the URL: the stylesheets are served without cache headers, so without it a browser can keep using a scheme compiled by an earlier build. The light scheme is re-pointed too, because the theme links it unversioned. The same version goes on our own scripts, so a stale theme-toggle.js cannot bring back the unversioned jtd.setTheme. {%- endcomment %} {%- assign asset_version = site.time | date: '%s' %}
