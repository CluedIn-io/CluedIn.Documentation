# Users and roles

Who can sign in, and what they are allowed to do. A user gets roles, a role carries claims and permissions, and access control decides which data each role can see.

## In this section

- [User management](https://documentation.cluedin.net/administer/users-and-roles/user-management.md) (how-to): In this article, you will learn how to add and deactivate users in your CluedIn organization.
- [Roles](https://documentation.cluedin.net/administer/users-and-roles/roles.md) (concept): In this article, you will learn about claims and access levels, which are the main concepts that define roles.
- [Assign or remove roles](https://documentation.cluedin.net/administer/users-and-roles/assign-roles.md) (how-to): In this article, you will learn how to assign and remove roles for users to manage their access to features within CluedIn.
- [Configure Microsoft Entra roles for multi-tenant SaaS SSO](https://documentation.cluedin.net/administer/users-and-roles/mt-saas-sso-roles.md) (how-to): This article explains how to configure Microsoft Entra application roles for CluedIn multi-tenant (MT) SaaS when using Microsoft Entra ID single sign-on (SSO) with automatic role synchronization.
- [Claims](https://documentation.cluedin.net/administer/users-and-roles/claims.md) (concept): In this article, you'll find detailed explanation of each claim used in CluedIn.
- [Process role requests](https://documentation.cluedin.net/administer/users-and-roles/process-role-requests.md) (how-to): In this article, you will learn how to process the role requests you receive from users to grant them the access they need.
- [User access](https://documentation.cluedin.net/administer/users-and-roles/user-access.md) (concept): In this section, you will learn about the main aspects that define user access in CluedIn.
- [Data access](https://documentation.cluedin.net/administer/users-and-roles/data-access.md) (how-to): In this article, you will learn about the main settings for configuring secure and reliable access to the data in CluedIn—source control and access control.
- [Feature access](https://documentation.cluedin.net/administer/users-and-roles/feature-access.md) (how-to): In this article, you will learn about the main settings that define access to CluedIn features: roles and ownership.
