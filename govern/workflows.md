# Workflows

The **Workflow** module is designed to help you streamline and track approvals and notifications for specific activities in CluedIn with the help of **Power Automate workflows**. This functionality is intended only for SSO users.

> **Important:** To use the Workflow module in CluedIn, you need to configure [Power Automate integration](https://documentation.cluedin.net/solutions/power-automate.md).

This section covers the following areas:

- [Concept of workflows](https://documentation.cluedin.net/govern/workflows/concept-of-approvals.md) – learn about the approval workflow and its participants.

- [Creating and managing workflows](https://documentation.cluedin.net/govern/workflows/create-and-manage-workflows.md) – learn how to create a workflow for automating a specific approval process and how to find the details about the actions that triggered workflow runs.

- [Manage approval requests](https://documentation.cluedin.net/govern/workflows/manage-approval-requests.md) – learn how to view, approve, or reject the approval requests.

## In this section

- [Concept of workflows](https://documentation.cluedin.net/govern/workflows/concept-of-approvals.md) (concept): Let's explore the concept of Power Automate workflows in CluedIn using an example of rule modification.
- [Create and manage workflows](https://documentation.cluedin.net/govern/workflows/create-and-manage-workflows.md) (how-to): In this article, you will learn how to create workflows for automating certain approval processes.
- [Manage approval requests](https://documentation.cluedin.net/govern/workflows/manage-approval-requests.md) (how-to): In this article, you will learn how to view, approve, and reject approval requests sent from the Power Automate widget in CluedIn.
