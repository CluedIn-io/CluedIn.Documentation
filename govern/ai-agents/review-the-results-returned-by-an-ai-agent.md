# Review the results returned by AI agent

> how-to: Steps to accomplish one task.

AI agents examine incoming data and provide suggestions based on configured prompts. These suggestions are not automatically applied to the golden records. Instead, you must review each suggestion and decide whether to apply or reject it. In this article, you will learn how to interpret, validate, and take action based on the outputs generated by AI agents.

You need to review the results of AI agent jobs that use the following [skills](https://documentation.cluedin.net/govern/ai-agents/create-configure-and-run-an-ai-agent.md#configure-a-prompt):

- **Create Rules**

- **Fix Data Quality Issues**

For the **Find Duplicates** skill, AI agent suggestions are approved automatically. This avoids a two-tier approval process, because matches within a [deduplication project](https://documentation.cluedin.net/master/deduplication.md) already require user approval.

Your administrator can enable the [automatic approval of AI agent suggestions](https://documentation.cluedin.net/govern/ai-agents/prerequisites-to-using-ai-agents.md#configure-organization-wide-settings-for-ai-agents). When this setting is turned on, you do not need to approve any results, regardless of the AI agent skill.

> **Important:** This article explains how to manage final suggestions generated by an AI agent. For details on how to view test run results, see [Test an AI agent job](https://documentation.cluedin.net/govern/ai-agents/create-configure-and-run-an-ai-agent.md#test-the-job).

**To review the results returned by an AI agent**

1. On the navigation pane, go to **AI Agents** (or, alternatively, **Management** > **AI Agents**).

1. Select the AI agent whose results you want to review, and then choose the job of interest.

1. On the job page, go to the **Results** tab. Here you can view the list of all suggestions generated by the AI agent.

    If the **Results** tab is empty, this may mean the following:

     - Your administrator [enabled the auto-approval of AI agent suggestions](https://documentation.cluedin.net/govern/ai-agents/prerequisites-to-using-ai-agents.md#configure-organization-wide-settings-for-ai-agents). In this case, all suggestions become approved as soon as the agent provides them. To view approved suggestions, in the status filter, select **Approved**.

        ![The Results tab of an AI agent job with the status filter set to Approved, listing one approved suggestion](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/status_filter_approved.png)

      - All suggestions from the AI agent were already approved or rejected (by you or another user).

      - The AI agent job is still running or was not [run](https://documentation.cluedin.net/govern/ai-agents/create-configure-and-run-an-ai-agent.md#run-the-job) at all. If the job is still running, you will see a progress bar at the top of the AI agent job page.

        ![An AI agent job page with a Processing 19.8% progress bar highlighted at the top](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/job_processing_status.png)

        To check if the job was run before, go to the **Runs** tab. If the job was run at least once (not in test mode), you will see at least one record with the **Completed** status and without the **Test** label.

        ![The Runs tab of an AI agent job with a Completed run that has no Test label highlighted](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/completed_job.png)

    You can also view AI agent suggestions on the **Runs** tab. However, you cannot approve or reject them from that tab. The layout of the **Runs** tab changes depending on the skill selected when [configuring the prompt](https://documentation.cluedin.net/govern/ai-agents/create-configure-and-run-an-ai-agent.md#configure-a-prompt). In the example above, the image is for the **Fix Data Quality Issues** skill.

1. (Optional) Filter the suggestions by business domain or suggestion status (pending, approved, or rejected). Select the **Pending** status if you want to approve and reject the suggestions.

    ![The Results tab with the business domain filter and the status filter, set to Pending, highlighted](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/filter_the_results.png)

1. Review each suggestion. Depending on the review result, do one of the following:

    - If the suggestion is correct and you want to apply the suggested changes, next to the suggestion, select **Approve**. The AI agent makes the suggested change to the golden record; information about this change is recorded in the [golden record history](https://documentation.cluedin.net/master/golden-records/history.md).

    - If the suggestion is incorrect or not necessary, next to the suggestion, select **Reject**.

        ![The Results tab with the Approve and Reject icons in the Actions column of each suggestion highlighted](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/approve_or_reject_single_suggestion.png)

     - To accept or reject all suggestions, in the upper-left corner of the **Results** tab, select **Approve All** or **Reject All**.

        ![The Results tab with the Reject all and Approve all buttons highlighted](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/approve_or_reject_all_suggestions.png)

     - To accept or reject specific suggestions only, select these suggestions. Then, in the upper-right corner of the **Results** tab, open the three-dot menu, and then select **Approve** or **Reject**.

        ![One suggestion selected on the Results tab, with the Reject selected and Approve selected buttons highlighted](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/approve_or_reject_specific_suggestions_sp.png)

    Once a suggestion is approved or rejected, its status changes accordingly (to **Approved** or **Rejected**). You can find this suggestion by selecting **Approved** or **Rejected** in the status filter.

    ![The Results tab of an AI agent job with the status filter set to Approved, listing one approved suggestion](https://documentation.cluedin.net/assets/images/management/ai-agents/review-the-results-by-an-ai-agent/status_filter_approved.png)

1. After you [run the job](https://documentation.cluedin.net/govern/ai-agents/create-configure-and-run-an-ai-agent.md#run-the-job), the AI agent may not immediately produce all expected suggestions. The recommended approach is to work iteratively – run the job, review the results, then run the job and review the results again. Repeat this process until the AI agent generates all expected suggestions.
