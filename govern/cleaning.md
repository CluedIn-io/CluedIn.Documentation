# Cleaning

Data cleaning helps you identify and correct any issues in your data: normalize value representations, transform capitalization, modify values, and more. After you've cleaned your data, you can use it to gain valuable insights that help you make more informed decisions.

In this section, you will learn how to fix data quality issues through the use of clean projects. In addition, you will learn how to proactively prevent the same data quality issues by generating rules based on your actions in the clean project.

The following diagram shows the basic steps of cleaning the data in CluedIn.

![Diagram: four steps to clean data in CluedIn - 1 identify data to be cleaned, 2 create a clean project choosing data and properties, 3 clean the data by transforming, normalizing and fixing values, 4 process cleaned data to send values to golden records](https://documentation.cluedin.net/assets/images/preparation/clean/clean-1.gif)

This section covers the following areas:

- [Creating a clean project](https://documentation.cluedin.net/govern/cleaning/create-clean-project.md) – discover different options that you can use to create a clean project.

- [Managing a clean project](https://documentation.cluedin.net/govern/cleaning/manage-clean-project.md) – learn how to work with a clean project, fix data issues, and prevent the same issues from happening again.

- [Reference information about clean projects](https://documentation.cluedin.net/govern/cleaning/clean-reference.md) – find information about clean project statuses and get an understanding of the clean project workflow.
