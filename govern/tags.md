# Tags

Tags are labels you attach to golden records and data parts. They do not overwrite anything - they classify, so that rules, filters, streams and reports can act on the classification.

## In this section

- [Tag monitoring](https://documentation.cluedin.net/govern/tags/tag-monitoring.md) (concept): Tags are an essential mechanism that helps you flag golden records that have data quality issues.
- [Use tags with rules](https://documentation.cluedin.net/govern/tags/use-tags-with-rules.md) (how-to): Tags in CluedIn allow you to add metadata labels to records that can drive automation, filtering, and reporting.
- [How to tag records with data quality issues](https://documentation.cluedin.net/govern/tags/how-to-tag-records-with-data-quality-issues.md) (how-to): In this article, you will learn how to tag records with data quality issues using golden record rules and CluedIn Copilot.
