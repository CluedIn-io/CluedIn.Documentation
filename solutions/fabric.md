# Microsoft Fabric


## In this section

- [Connect CluedIn to Microsoft Fabric](https://documentation.cluedin.net/solutions/fabric/connect-cluedin-to-fabric.md) (how-to): In this article, you will learn how to load data from CluedIn to a Microsoft Fabric notebook, do basic data exploration and transformation, and save data in a Delta Lake table.
- [Connect Microsoft Fabric to CluedIn](https://documentation.cluedin.net/solutions/fabric/connect-fabric-to-cluedin.md) (how-to): In this article, you will learn how to load the data from Microsoft Fabric to CluedIn.
- [Use CluedIn rules in Microsoft Fabric](https://documentation.cluedin.net/solutions/fabric/use-cluedin-rules-in-fabric.md) (how-to): CluedIn provides a powerful GraphQL API for retrieving data and metadata and executing actions.
- [Use CluedIn's Microsoft Fabric Workload](https://documentation.cluedin.net/solutions/fabric/use-cluedin-fabric-workload.md) (how-to): CluedIn provides a native Microsoft Fabric Workload that can take data in your Fabric environment and clean it through the CluedIn Clean application.
