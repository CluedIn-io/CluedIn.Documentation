# Administer

How do I manage the product?
  CluedIn administrators working inside the product.

Everything an administrator does **inside** CluedIn: who can sign in, what they can see and do, how the interface is configured, and how API access is issued.

Running the platform itself - deploying, upgrading, backing up - is [Deploy & operate](https://documentation.cluedin.net/operate.md).

## In this section

- [Users and roles](https://documentation.cluedin.net/administer/users-and-roles.md): Who can sign in, and what they are allowed to do.
- [Access control](https://documentation.cluedin.net/administer/access-control.md): Access control policies decide which golden records and which properties a role can see.
- [UI configuration](https://documentation.cluedin.net/administer/ui-configuration.md): What users see when they open CluedIn: the layout of a golden record page, the items in the navigation menu, and the language the interface uses for your business domains.
- [Feature flags](https://documentation.cluedin.net/administer/feature-flags.md) (reference): In this article, you will learn about the features in CluedIn that you can turn on or off as needed.
- [Generate an API token](https://documentation.cluedin.net/administer/api-token.md) (how-to): API tokens allow external systems and applications to authenticate and interact with CluedIn programmatically.
- [Jobs](https://documentation.cluedin.net/administer/jobs.md) (how-to): The Jobs module lets you schedule recurring work in CluedIn and monitor when that work runs.
- [General settings](https://documentation.cluedin.net/administer/general-settings.md) (reference): The Notifications section lets you control how you, personally, are notified about activity in CluedIn.
