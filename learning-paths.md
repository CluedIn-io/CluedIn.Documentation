# Learning paths

How do I learn CluedIn for my role?
  New users following a structured course.

Role-based courses that sequence the product documentation into a learning order. Each module explains the *why*, then links to the canonical article for the *how* - so there is only ever one explanation of a feature to keep up to date.

## In this section

- [Data Steward course](https://documentation.cluedin.net/learning-paths/data-steward.md): For the person who reviews, corrects and approves data every day.
- [Data Architect course](https://documentation.cluedin.net/learning-paths/data-architect.md): For the person who decides how CluedIn is set up: the model, the ingestion design, the matching strategy, and the path from development to production.
- [CluedIn fundamentals](https://documentation.cluedin.net/learning-paths/fundamentals.md): The base training course: get data in, build a single view of a customer, and spot what is wrong with it.
- [AI in CluedIn](https://documentation.cluedin.net/learning-paths/ai.md): Where AI fits in CluedIn: agents that do stewardship work, the AI enricher, and Copilot - each with a demo you can follow.
- [Role handbooks](https://documentation.cluedin.net/learning-paths/role-handbooks.md): One condensed handbook per role: what you are responsible for, what you touch in the product, and the order to learn it in.
