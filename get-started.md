# Get started

What is CluedIn and how do I begin?
  Anyone opening CluedIn for the first time.

CluedIn takes messy data from many systems and turns it into golden records you can trust. This section explains what the platform does, defines the terms used everywhere else in the documentation, and walks you through your first end-to-end run.

Once you are oriented, the rest of the documentation follows the data lifecycle: [Ingest](https://documentation.cluedin.net/ingest.md) -> [Model](https://documentation.cluedin.net/model.md) -> [Master](https://documentation.cluedin.net/master.md) -> [Govern & improve](https://documentation.cluedin.net/govern.md) -> [Publish & consume](https://documentation.cluedin.net/publish.md).
